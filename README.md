# Philly AI Leasing Assistant

## Overview

This project is a prototype AI leasing assistant built using Philadelphia-area multifamily real estate data.

The purpose is to explore how AI can support leasing and marketing teams by reducing repetitive renter communication and organizing inbound inquiries.

The workflow includes:

- storing multifamily property data
- organizing renter inquiries
- generating AI leasing replies
- supporting faster communication with prospective renters

This project uses real property analysis from a Philadelphia-area multifamily investment project centered on Plymouth Pointe Apartments in Norristown, PA.

## Sample Leasing Workflow

Example renter questions include:

- Is Plymouth Pointe pet friendly?
- Can I schedule a tour this Saturday?
- Is parking included with rent?
- How much is rent for a one-bedroom?
- Can I move in August 1?

The AI workflow generates leasing response drafts based on each inquiry.

Example:

**Renter:**  
“Hi! Is Plymouth Pointe pet friendly?”

**AI Response:**  
“Thanks for reaching out! Plymouth Pointe Apartments is pet friendly and includes a dog park on-site. We'd be happy to answer additional questions or help schedule a tour.”
